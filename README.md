# MockPrep — Placement Mock Test Platform 🎯

A premium, timed mock test platform for placement exam preparation. Built with pure HTML, CSS, and JavaScript.

## Features

- ⏱️ **Timed Tests** matching real exam patterns
- 📝 **1,000 SSC CHSL practice questions** plus company-specific mock banks, based on published syllabi and past-paper patterns
- 📊 **Detailed Results** with topic-wise breakdown & explanations
- 🚩 **Flag for Review** and keyboard shortcuts
- 📈 **Progress Tracking** with localStorage history
- 🌙 **Dark Mode** with glassmorphism design

## Currently Available

- **Accenture** — Technical MCQ, Communication, Cognitive, Coding (external links)
- **Capgemini** — English Communication, Problem Solving, AI-assisted Debugging, AI-assisted Feature Development, Prompt Engineering, Cognitive Assessment, and hard coding practice
- **SSC CHSL Tier-I** — 10 full mocks (1,000 questions), strict 15-minute sections, +2/−0.50 scoring, and detailed answer review

## How to Use

1. Open `index.html` in your browser
2. Select a company and start a mock test
3. Take the timed mock test
4. Review your results and study recommendations

The SSC CHSL mock runner is in `ssc-chsl/` and can also be opened directly at `ssc-chsl/SSC_CHSL_Tier1_Mock_Exam.html`.
