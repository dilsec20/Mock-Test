# MockPrep — Placement Mock Test Platform 🎯

A premium, timed mock test platform for placement exam preparation. Built with pure HTML, CSS, and JavaScript.

## Features

- ⏱️ **Timed Tests** matching real exam patterns
- 📝 **120+ Questions** sourced from latest syllabus & PYQs
- 📊 **Detailed Results** with topic-wise breakdown & explanations
- 🚩 **Flag for Review** and keyboard shortcuts
- 📈 **Progress Tracking** with localStorage history
- 🌙 **Dark Mode** with glassmorphism design

## Currently Available

- **Accenture** — Technical MCQ, Communication, Cognitive, Coding (external links)

## How to Use

1. Open `index.html` in your browser
2. Select a company and section
3. Take the timed mock test
4. Review your results and study recommendations
